# مشاريع الويب

هذا المستودع يحتوي على ثلاثة أشياء:

| المجلد | ما هو |
|---|---|
| `studio/` | **الاستوديو** — يبني موقعًا كاملًا من خمسة حقول، ويضع البيانات في الرابط |
| `portfolio/` | **الموقع الشخصي** — النماذج والأسعار والتواصل: الرابط الذي تعطيه للعملاء |
| الجذر (`index.html`) | **متجر نور** — نموذج متجر إلكتروني كامل |
| `demo-restaurant/` | **دار الياسمين** — نموذج موقع مطعم فاخر مع حجز طاولات |
| `demo-school/` | **مدرسة النخبة** — نموذج مدرسة خاصة وروضة مع استمارة تسجيل |
| `sales/` | **عُدّة البيع** — الميادين والأسعار والتفاوض ونصوص التواصل |
| `sales/card/` | **بطاقة العرض** — أداة تعبئة وطباعة بقياس A5 مع كود QR |

النماذج الثلاثة جاهزة للعرض على العملاء. ابدأ من [`sales/README.md`](sales/README.md).

# متجر نور — موقع متجر إلكتروني بسيط

متجر تجريبي كامل مبني بـ **HTML و CSS و JavaScript فقط** — بدون أطر عمل، وبدون أدوات بناء، وبدون خادم.
كل شيء يعمل داخل المتصفح، وتُحفظ السلة في `localStorage`.

## المميّزات

- **صفحة رئيسية** فيها واجهة ترحيبية، قسم عروض، وشبكة منتجات.
- **بحث وتصفية وترتيب**: بحث فوري في الأسماء والمواصفات، تصفية حسب التصنيف، وترتيب حسب السعر أو التقييم أو الاسم.
- **صفحة منتج** بتفاصيل ومواصفات وحالة المخزون ومنتجات مقترحة (`product.html?id=p-01`).
- **سلة مشتريات** تعمل فعليًا: إضافة، تعديل الكمية، حذف، إفراغ، ومزامنة بين تبويبات المتصفح.
- **أكواد خصم** واحتساب الشحن (مجاني ابتداءً من 8000 دج).
- **إتمام طلب** بنموذج مع تحقّق من المدخلات ورسائل خطأ عربية، ثم صفحة تأكيد برقم طلب.
- **تصميم متجاوب** يعمل على الجوّال، مع **دعم الوضع الداكن** تلقائيًا حسب إعداد النظام.
- **اتجاه من اليمين إلى اليسار** بالكامل، وواجهة عربية، وروابط تخطّي وتسميات وصول (a11y).

## التشغيل محليًا

أي خادم ملفات ثابت يكفي:

```bash
# باستخدام Python
python3 -m http.server 8000

# أو باستخدام Node
npx http-server -p 8000
```

ثم افتح <http://localhost:8000>.

> فتح `index.html` مباشرة من القرص يعمل أيضًا، لكن تشغيله عبر خادم أقرب لسلوك الاستضافة الحقيقية.

## النشر على GitHub Pages

الموقع ثابت بالكامل، لذا يكفي:

1. من صفحة المستودع: **Settings › Pages**.
2. في **Source** اختر **Deploy from a branch**.
3. اختر الفرع المطلوب والمجلد `/ (root)` ثم **Save**.

## بنية الملفات

```
index.html          الصفحة الرئيسية
product.html        صفحة تفاصيل المنتج
cart.html           السلة وإتمام الطلب
css/styles.css      كل الأنماط (متغيّرات لونية + وضع داكن + استجابة)
js/data.js          المنتجات والتصنيفات وأكواد الخصم وإعدادات الشحن
js/store.js         منطق مشترك: السلة، التنسيق، التنبيهات، بطاقة المنتج
js/home.js          البحث والتصفية والترتيب في الصفحة الرئيسية
js/product.js       عرض تفاصيل المنتج والمقترحات
js/cart.js          عناصر السلة، الخصم، الملخّص، ونموذج الطلب
assets/img/*.svg    صور المنتجات (SVG بسيطة، بلا اعتماد على الإنترنت)
```

## تعديل المنتجات

كل البيانات في ملف واحد: `js/data.js`. لإضافة منتج، أضف عنصرًا إلى مصفوفة `PRODUCTS`:

```js
{
  id: 'p-13',                       // معرّف فريد
  name: 'اسم المنتج',
  category: 'home',                 // tech | home | office
  price: 199,
  oldPrice: 249,                    // أو null إن لم يكن هناك تخفيض
  rating: 4.5,
  reviews: 30,
  stock: 10,                        // 0 يعني «نفد المخزون»
  image: 'assets/img/mug.svg',
  short: 'وصف قصير يظهر في البطاقة.',
  description: 'وصف مفصّل يظهر في صفحة المنتج.',
  features: ['ميزة أولى', 'ميزة ثانية']
}
```

كما يمكنك تعديل `PROMO_CODES` و`SHIPPING_FEE` و`FREE_SHIPPING_FROM` في الملف نفسه.
العملة والشحن في نهاية `js/data.js`. لتغيير الألوان، عدّل المتغيّرات في أعلى `css/styles.css` (`--brand` و`--accent` وغيرها).

## أكواد الخصم للتجربة

| الكود | الأثر |
|---|---|
| `WELCOME10` | خصم 10% على المجموع الفرعي |
| `FREESHIP` | شحن مجاني |
| `SAVE800` | خصم ثابت 800 دج |

## ملاحظة

هذا متجر **تجريبي**: لا توجد أي عملية دفع حقيقية، ولا يُرسل أي طلب إلى أي خادم.
الطلب المؤكَّد يُعرض في المتصفح فقط، والسلة تُحفظ محليًا على جهاز الزائر.

# دار الياسمين — نموذج موقع مطعم

موقع مطعم فاخر من صفحة واحدة، في `demo-restaurant/`. مبني بنفس الطريقة:
HTML و CSS و JavaScript فقط.

**ما فيه:** واجهة بملء الشاشة، شريط معلومات (ساعات العمل والهاتف والعنوان)،
قسم تعريفي، **قائمة طعام بأقسام قابلة للتبديل** بتصميم طباعي كلاسيكي،
معرض صور، آراء الضيوف، **نموذج حجز طاولة** بتحقّق كامل من المدخلات
(لا يقبل تاريخًا ماضيًا) وصفحة تأكيد، وقسم تواصل مع مساحة خريطة.

**لتخصيصه لمطعم حقيقي:**

1. `demo-restaurant/js/restaurant.js` — عدّل ثابت `MENU` في أعلى الملف
   (الأقسام والأطباق والأسعار والأوصاف).
2. `demo-restaurant/index.html` — غيّر الاسم والعنوان والهاتف والنصوص.
3. `demo-restaurant/img/` — استبدل ملفات SVG بصور المطعم الحقيقية
   (احتفظ بالأسماء نفسها، أو حدّث المسارات في HTML).
4. `demo-restaurant/css/restaurant.css` — الألوان في `:root` أعلى الملف
   (`--gold` هو لون العلامة، و`--ink` هو الخلفية الداكنة).

احذف عنصر `<p class="demo-flag">` من `index.html` في النسخة الحقيقية.

# مدرسة النخبة — نموذج موقع مدرسة وروضة

موقع مدرسة خاصة وروضة أطفال، في `demo-school/`. نفس البناء: HTML و CSS
و JavaScript فقط.

**ما فيه:** واجهة بأرقام تُطمئن الأولياء (عدد التلاميذ في القسم، اللغات،
سنة التأسيس)، قسم تعريفي، **بطاقات الأطوار الثلاثة**، **جدول اليوم الدراسي
بالساعة** (أكثر ما يسأل عنه الأولياء)، **جدول رسوم معلن** — وهو أقوى إشارة
ثقة في الموقع كله — و**استمارة تسجيل أوّلي** بتحقّق كامل يرفض تاريخ ميلاد
خارج مدى 2–16 سنة، وأسئلة شائعة قابلة للطيّ، وقسم تواصل.

**لتخصيصه لمؤسسة حقيقية:**

1. `demo-school/js/school.js` — ثابت `FAQ` في أعلى الملف (الأسئلة والأجوبة).
2. `demo-school/index.html` — الاسم والأطوار وجدول الرسوم واليوم الدراسي
   والعنوان والهاتف.
3. `demo-school/img/` — استبدل ملفات SVG بصور المؤسسة الحقيقية.
4. `demo-school/css/school.css` — الألوان في `:root` (`--deep` لون المؤسسة،
   `--amber` لمسة الدعوة إلى الفعل).

احذف `<p class="demo-flag">` في النسخة الحقيقية.

> **ملاحظة عن كتابة المبالغ:** اكتب الآلاف بمسافة ضيّقة غير فاصلة
> (`U+202F`) لا بمسافة عادية — وإلا عكسها المتصفّح في السياق العربي
> فظهرت «180 000» كـ«000 180».

# الموقع الشخصي

في `portfolio/`. صفحة واحدة تجمع النماذج الثلاثة والخدمة الشهرية والأسعار
ونموذج تواصل يفتح واتساب برسالة مكتوبة مسبقًا.

**هذا هو الرابط الذي يجب أن يقود إليه كود QR على بطاقة العرض** — لا نموذج
بعينه. الزائر يصل إليك أنت، فيرى النماذج والأسعار ورقمك في مكان واحد.

**قبل استعماله، غيّر ثلاثة أشياء:**

1. `portfolio/index.html` — رقم الهاتف في قسم التواصل (يظهر مرتين:
   في `tel:` وفي النص).
2. `portfolio/js/site.js` — الرقم داخل رابط `wa.me` بالصيغة الدولية بلا
   رموز (`213` ثم الرقم بلا الصفر الأول).
3. `portfolio/js/site.js` — ثابت `BASE` إن نشرت النماذج على عنوان آخر.

الأسعار في ثابت `PLANS` بالملف نفسه، والخدمة الشهرية في `FLOW`.

# الاستوديو

في `studio/`. أداة بيع لا موقعًا: تكتب اسم المؤسسة ومجالها ولونها وهاتفها،
فيُبنى موقع كامل أمامك في إطار هاتف — ثم تنسخ رابطًا ترسله في واتساب.

**كيف يعمل بلا خادم:** البيانات كلها في **جزء الرابط بعد `#`**، وهذا الجزء
لا يُرسل إلى أي خادم أصلًا. الصفحة تقرأه وتبني منه الموقع في المتصفّح.
لذلك ينشر على GitHub Pages ويعمل كما هو، ويصلح لعدد غير محدود من العملاء
بملف واحد.

```
studio/index.html#name=مقهى+الشروق&sector=resto&color=%23b4531f&v=1
```

`v=1` تعني وضع العرض: تظهر الصفحة وحدها بملء الشاشة بلا أدوات التحرير.

**المجالات الستة** معرّفة في `studio/js/sectors.js`: مطعم، مدرسة أو روضة،
قاعة حفلات، عيادة، قاعة رياضة، محلّ. لإضافة مجال، أضف مفتاحًا إلى `SECTORS`
بالبنية نفسها — تظهر في القائمة تلقائيًا.

**اللوحة اللونية تُشتقّ من لون واحد** عبر تحويل HSL في `palette()`: درجة
داكنة للنصوص، وأخرى فاتحة جدًا للخلفيات. فيكفي أن تسأل صاحب المؤسسة عن
لون لافتته.

**ملاحظة أمان:** كل ما يأتي من الرابط يُهرَّب قبل إدراجه في الصفحة
(الدالة `esc`)، فلا يمكن حقن HTML عبر اسم مؤسسة مُعدّ خصّيصًا.

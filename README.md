# حقّي — منصة قانونية بالدارجة لحقوق المرأة الجزائرية

موقع توعوي يشرح حقوق المرأة في **الطلاق، النفقة، الحضانة، السكن، الميراث، وحقوق العاملة** بالدارجة الجزائرية، مع **نماذج عرائض جاهزة** و**دليل الجهات**.

> ⚠️ **المحتوى في طور المراجعة القانونية.** كل المراجع مجمّعة في [`REVISION-JURIDIQUE.md`](REVISION-JURIDIQUE.md) وتحتاج تأكيداً مقابل النصوص الرسمية قبل النشر العلني. الصفحات غير المراجَعة تعرض تنبيهاً واضحاً للزائرة.

## واش فيه

- **7 أدلة** — الطلاق، النفقة، الحضانة، السكن، الميراث، حقوق العاملة، العنف الزوجي
- **6 نماذج جاهزة** — عرائض، شكاوى، طلب تنفيذ، طلب المساعدة القضائية (قابلة للطباعة)
- **26 سؤالاً وجواباً** مع بيانات `FAQPage` المهيكلة لغوغل
- **دليل الجهات** — وين تروحي، واش تدير كل جهة، وواش تجيبي معاك

## البنية التقنية

مولّد مواقع ستاتيك مكتوب بـ Node، **بصفر تبعيات خارجية**. المحتوى في Markdown، والمخرجات HTML ستاتيك.

```
content/           ← المحتوى (هنا تحرّرين)
  site.json          إعدادات الموقع والقائمة
  guides/*.md        الأدلة
  namadhij/*.md      النماذج
  faq.json           الأسئلة والأجوبة
  dalil.json         دليل الجهات
lib/               ← محلّل Markdown + القوالب
assets/            ← CSS، JS، الأيقونة
build.js           ← المولّد
public/            ← المخرجات (مولّدة، ما تتحرّرش)
REVISION-JURIDIQUE.md  ← قائمة المراجعة القانونية (مولّدة)
```

## التشغيل

```bash
npm run build     # يولّد public/ ويحدّث REVISION-JURIDIQUE.md
npm run serve     # يبني ويشغّل خادماً محلياً على http://localhost:8080
npm run check     # يبني ويفشل إذا كان في محتوى ناقص البيانات الوصفية
```

ما يحتاجش `npm install` — ما كاينش تبعيات.

## كيفاش تزيدي دليلاً جديداً

أنشئي `content/guides/<slug>.md`:

```markdown
---
title: عنوان الصفحة
slug: my-slug
description: وصف قصير يظهر في غوغل وفي البطاقات.
category: الأسرة
icon: ⚖️
order: 8
updated: 2026-09
revision: pending
---

نصّ بالدارجة...

:::law المادة 74 من قانون الأسرة
نصّ المادة كما هو في القانون.
:::

:::step
1. الخطوة الأولى
2. الخطوة الثانية
:::

:::note معلومة مفيدة
...
:::

:::warn تحذير
...
:::
```

ثم `npm run build`. الصفحة تظهر أوتوماتيكياً في الرئيسية، في فهرس الأدلة، في `sitemap.xml`، وفي قائمة المراجعة القانونية.

لربط نموذج بدليل، حطّي `guide: <slug الدليل>` في front-matter تاع النموذج.

## سير المراجعة القانونية

1. `npm run build` يجمع **كل** كتلة `:::law` في `REVISION-JURIDIQUE.md` مع مكانها.
2. تراجعين المراجع وحدة بوحدة مقابل النصّ الرسمي.
3. بعد ما تتأكّد صفحة كاملة، بدّلي `revision: pending` لـ `revision: verified` في front-matter.
4. تنبيه المراجعة يختفي من الصفحة أوتوماتيكياً.

## النشر

سير عمل GitHub Actions ينشر `public/` على GitHub Pages عند كل دفع لـ `main`. فعّلي Pages في إعدادات المستودع مع المصدر **GitHub Actions**، وحدّثي `baseUrl` في `content/site.json` بالنطاق الحقيقي.

## الخصوصية والسلامة

بلا حسابات، بلا كوكيز، بلا تتبّع، وبلا نماذج تجمع معطيات. الموقع فيه **زرّ خروج سريع** (وكذلك `Échap` ثلاث مرات) يستبدل الصفحة بموقع محايد بلا ما يخلّي أثراً في زرّ الرجوع.

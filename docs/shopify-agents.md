# فريق وكلاء Shopify (3 Sub-agents)

```
          المستخدم
             │
     الوكيل الرئيسي (المنسّق)
             │
 ┌───────────┼────────────────────────┐
 ▼           ▼                        ▼
shopify-analyst ──تقرير التسليم──► shopify-catalog ──سجلّ الكتالوج──► shopify-marketing
 (قراءة فقط)        [C#] [M#]        (منتجات/مخزون)                    (خصومات/حملات)
```

| الوكيل | الملف | يكتب في المتجر؟ | المسؤولية |
|---|---|---|---|
| shopify-analyst | `.claude/agents/shopify-analyst.md` | ❌ لا | تحليلات ShopifyQL، طلبات، عملاء، مخزون ← توصيات |
| shopify-catalog | `.claude/agents/shopify-catalog.md` | ✅ بعد التأكيد | منتجات، مجموعات، SEO، مخزون |
| shopify-marketing | `.claude/agents/shopify-marketing.md` | ✅ بعد التأكيد | أكواد خصم، عروض، استهداف |

## كيف يتعاونون

- **عقد التسليم:** المحلّل يُنهي كل رد بـ «تقرير التسليم» يحتوي توصيات مرقّمة
  `[C1]…` للكتالوج و`[M1]…` للتسويق. كل وكيل ينفّذ رموزه فقط.
- **فصل الصلاحيات:** المحلّل لا يملك أدوات كتابة؛ الكتالوج لا ينشئ خصومات؛
  التسويق لا يعدّل المنتجات أو المخزون. هذا يمنع التعارض.
- **الموافقة البشرية:** كل كتابة (مخزون، حالة جماعية، خصم، mutation) تتطلّب تأكيداً صريحاً.
- **حلقة المتابعة:** سجلّ التسويق يذكر مؤشرات يراقبها المحلّل في الجولة التالية.

## أمثلة استخدام

- «حلّل متجري وحسّنه» ← analyst ثم catalog ثم marketing.
- «جهّز حملة للمنتجات الراكدة» ← analyst (تحديد الراكد) ثم marketing.
- «أصلح المنتجات بلا صور أو وصف» ← analyst ثم catalog.
- يمكن أيضاً استدعاء أي وكيل مباشرة: «استعمل shopify-marketing لإنشاء كود 10%».

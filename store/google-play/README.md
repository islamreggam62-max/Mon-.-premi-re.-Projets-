## Upload key and signed bundle

Google Play accepts only a signed bundle (`.aab`). The CI workflow `.github/workflows/android.yml` signs `app-release.aab` when four repository secrets exist.

1. **Create the upload key once, on a computer with Java.** Android Studio includes Java. Keep the file and both passwords safe:
   ```
   keytool -genkeypair -v -keystore nexora-upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
2. **Encode it in base64:**
   - Linux: `base64 -w0 nexora-upload.jks > upload.txt`
   - macOS: `base64 -i nexora-upload.jks -o upload.txt`
   - Windows: `certutil -encode nexora-upload.jks upload.txt`, then delete the first and last lines.
3. **Add four secrets** in GitHub → repository → Settings → Secrets and variables → Actions:

   | Secret | Value |
   |---|---|
   | `ANDROID_UPLOAD_KEYSTORE_BASE64` | content of `upload.txt` |
   | `ANDROID_UPLOAD_STORE_PASSWORD` | keystore password |
   | `ANDROID_UPLOAD_KEY_ALIAS` | `upload` |
   | `ANDROID_UPLOAD_KEY_PASSWORD` | key password |

4. **Build a signed bundle.** Run the "Android build" workflow (Actions → Android build → Run workflow). Download `nexora-android` and upload `app-release.aab` to the Play Console.
5. **Keep Play App Signing on** (the default). Google keeps the app signing key. If the upload key is lost, the account owner can ask Google to reset it.

Before each new upload, raise `versionCode` in `android/app/build.gradle`. Play refuses a code it has already received.

## Closed test with 12 testers

New personal developer accounts must run a closed test before production: at least 12 testers, opted in for the 14 consecutive days before you apply. Organization accounts are exempt.

1. Play Console → Test and release → Testing → Closed testing → create a track and upload `app-release.aab`.
2. Add the testers' Google account emails as a list or a Google Group.
3. Send them the opt-in link with the message below. They accept, install from Play, and keep the app for 14 days.
4. Then apply for production access from the Dashboard.

## Steps in order

1. Create the Play Console developer account and verify your identity. Personal or organization: see above.
2. Merge PR #9 so the privacy policy on GitHub Pages is the current one, then open the URL to check it.
3. Create the upload key and add the four secrets. Run the Android build to get a signed `app-release.aab`.
4. In the Play Console, create the app: name, default language English (United States), app (not game), free.
5. Fill in the store listing (three languages above), the assets, and the App content forms.
6. Run the closed test with 12 testers for 14 days.
7. Apply for production access. When it is granted, create the production release with the same bundle or a newer one.

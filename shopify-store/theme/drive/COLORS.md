# نظام الألوان الجديد

الشكوى كانت صحيحة: كانت أزرار **كحلي باهت `#0c345a`** على أبيض، وشريط ثقة بلون رمادي-أزرق شاحب.
تصميم صحيح البنية لكن **بلا طاقة** — لا شيء يجذب العين أو يدفع للضغط.

## المعادلة الجديدة: كحلي عميق + كهرماني

نفس منطق أمازون ونون — لون هادئ يبني الثقة، ولون دافئ واحد يحمل كل أزرار الشراء.

| الدور | اللون | الاستعمال |
|-------|-------|-----------|
| **الكهرماني** | `#FF9F1C` | **كل أزرار الشراء** + شريط الثقة |
| **الكحلي العميق** | `#0F1E3D` | النصوص، العناوين، الأقسام الداكنة |
| نص الأزرار | `#0F1E3D` على الكهرماني | تباين عالٍ — الأبيض على الكهرماني غير مقروء |
| أبيض | `#FFFFFF` | الخلفية الأساسية |
| رمادي مزرق | `#F3F6FB` | أقسام متبادلة |
| أحمر التخفيض | `#D92D20` | شارات SALE |

## إيقاع الأقسام (لا ٣ أقسام بيضاء متتالية)

```
Hero            كحلي داكن مع تدرّج
▸ شريط الثقة    🟠 كهرماني كامل العرض  ← أقوى عنصر بصري
المزايا          أبيض
تسوّق حسب الفئة  رمادي مزرق
Best sellers     أبيض
قصة العلامة      كحلي داكن
Kitchen          أبيض
Before you order رمادي مزرق
```

## إصلاحات إضافية

| قبل | بعد | لماذا |
|-----|-----|-------|
| `scheme-5` **غير معرّف** | معرّف بالأحمر | شارات SALE كانت تشير لنظام ألوان غير موجود |
| زوايا الأزرار `0` | `40` | حواف دائرية = إحساس حديث |
| حجم H1 `88px` | `64px` | ٨٨ يفيض على الجوال |
| حجم النص `14px` | `16px` | ١٤ صغير جداً ويسبّب تكبيراً تلقائياً في iOS |
| شارات مربّعة | حبّات دائرية + uppercase | |
| تظليل الـHero أسود | كحلي `#0F1E3Dbf` | ينسجم مع الهوية |

## ⚠️ التباين
الكهرماني فاتح — **نص الأزرار كحلي لا أبيض**. لا تعكسها من المحرّر وإلا صار الزر غير مقروء.

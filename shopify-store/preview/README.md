# معاينة التصميم

`storefront-preview.html` — افتحه في أي متصفّح (ملف واحد، بدون تثبيت أي شيء).

يعرض تصميم الصفحة الرئيسية كما سيظهر فعلاً:
شريط الإعلان، الهيدر، الـHero، المزايا، الأكثر مبيعاً، الأسئلة الشائعة، شارات الثقة، والفوتر.

## الأزرار في الأعلى

| الزر | ماذا يُظهر |
|------|-------------|
| **English / العربية** | تبديل اللغة — والتخطيط كله ينعكس RTL تلقائياً |
| **USD / SAR / AED** | الأسعار المعتمدة بالعملات الثلاث |
| **Desktop / Phone** | عرض الجوال — ويظهر معه شريط الإضافة للسلة الثابت |

## ما هو حقيقي وما هو مؤقت

- ✅ **حقيقي:** العناوين، الأسعار، نصوص الأسئلة الشائعة، الألوان، الخطوط، التخطيط — كلها مطابقة لما في `theme/` و `products/`
- ⏳ **مؤقت:** صور المنتجات (رسوم توضيحية) لأن الصور لم تصل بعد، واسم المتجر `YOUR STORE`

## ملاحظة

هذه معاينة ثابتة للتصميم، وليست متجراً يعمل — الأزرار لا تضيف للسلة فعلاً.
الكود الحقيقي القابل للتركيب موجود في `../theme/`.

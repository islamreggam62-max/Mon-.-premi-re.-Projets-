### 🚫 ممارسات ممنوعة (تضر أكثر مما تنفع)
- عدّاد تنازلي وهمي يعيد نفسه عند التحديث
- "12 شخصاً يشاهدون هذا المنتج الآن" وهي أرقام عشوائية
- سعر مقارنة لم يكن حقيقياً أبداً
- تقييمات مستوردة أو مفبركة

هذه ليست مسألة أخلاق فقط: **Meta و TikTok و Google يرفضون الحسابات بسببها**، وقوانين حماية المستهلك في السعودية والإمارات تمنعها.

## القياس

فعّل في `Analytics`:
- Google Analytics 4
- Meta Pixel + Conversions API
- TikTok Pixel

راقب أسبوعياً:

| المؤشّر | هدف صحي |
|---------|----------|
| معدّل التحويل | 1.5–3% (متجر جديد)، 3%+ (ناضج) |
| Add to Cart rate | 5–10% |
| نسبة إتمام Checkout | ≥ 50% |
| نسبة الارتداد على صفحة المنتج | ≤ 60% |
| متوسط قيمة الطلب | ارفعه بالتقسيط والحزم |

## ترتيب التنفيذ الموصى به

```
الأسبوع 1: البنود 1–13  (الرئيسية + صفحات المنتجات)
الأسبوع 2: البنود 14–25 (السلة + Checkout)
الأسبوع 3: البنود 26–37 (السرعة + الثقة)
```

**لا تُطلق إعلانات قبل إنهاء الأسبوع الأول والثاني.** الزيارات المدفوعة على متجر ضعيف التحويل = حرق مال مباشر.

# املأ هذه القيم قبل النشر — استبدلها في كل ملفات `pages/`

> ⚠️ **لا تنشر أي صفحة وفيها قيمة `[[...]]` لم تُملأ.** هذه الصفحات لها أثر قانوني.
> ⚠️ **لا تخترع عنواناً أو رقم سجل تجاري.** إن لم يكن لديك كيان مسجّل بعد، احذف السطر بالكامل بدل كتابة معلومة غير حقيقية.

| Placeholder | المعنى | مثال على الشكل المطلوب |
|---|---|---|
| `[[STORE_NAME]]` | اسم المتجر التجاري | اسم متجرك الحقيقي |
| `[[STORE_DOMAIN]]` | النطاق | `example.com` |
| `[[SUPPORT_EMAIL]]` | بريد الدعم الفعّال | بريد تقرأه فعلاً يومياً |
| `[[SUPPORT_PHONE]]` | واتساب/هاتف الدعم | اتركه فارغاً واحذف السطر إن لم يوجد |
| `[[BUSINESS_ADDRESS]]` | العنوان المسجّل | **فقط إذا كان حقيقياً** — وإلا احذف السطر |
| `[[LEGAL_ENTITY]]` | الاسم القانوني للكيان | **فقط إذا كان مسجّلاً** — وإلا احذف السطر |
| `[[PROCESSING_DAYS]]` | أيام تجهيز الطلب | مثال: `1–3` |
| `[[DELIVERY_WINDOW]]` | مدة التوصيل الفعلية | **ضع المدة الحقيقية من مورّدك** — الوعد الكاذب هنا يسبب نزاعات واسترجاعات |
| `[[RETURN_WINDOW]]` | مدة الاسترجاع | مثال: `30` |
| `[[RETURN_ADDRESS]]` | عنوان الاسترجاع | عنوان حقيقي أو اكتب أن العنوان يُرسل بعد اعتماد الطلب |
| `[[GOVERNING_LAW]]` | القانون الحاكم | البلد الذي يقع فيه كيانك القانوني |

## أمر بحث سريع للتأكّد من عدم بقاء أي placeholder

```bash
grep -rn '\[\[' shopify-store/pages/ && echo "⚠️ ما زالت هناك قيم غير مملوءة" || echo "✅ كل القيم مملوءة"
```

# سكريبتات إعلانات الفيديو — TikTok / Reels

هدفك: فيديو 15–30 ثانية يوقف التمرير ويحوّل المشاهدة إلى نقرة على المتجر.
المعركة تُكسب أو تُخسر في **أول 3 ثوانٍ**.

## قبل الكتابة

اجمع أو اسأل عن: المنتج ومشكلته، الجمهور والسوق/اللغة، أهم ميزة واحدة،
والعرض (سعر/خصم/شحن). حدّد **زاوية واحدة** لكل فيديو (لا تحشُ كل شيء).

## بنية السكريبت (30 ثانية)

1. **الخطّاف (0–3 ث):** اكتب 3 خيارات مختلفة للاختبار. أنماط تعمل:
   - مشكلة صادمة: «توقّف عن … إن كنت تعاني من …».
   - نتيجة/قبل-بعد: «هكذا حلّيت … في يومين».
   - فضول: «لا أحد يخبرك بهذه الحيلة عن …».
2. **المشكلة (3–8 ث):** لمس ألم العميل بصرياً + صوتياً.
3. **الحل (8–18 ث):** قدّم المنتج والميزة الأساسية أثناء عرضه يُستخدم فعلاً.
4. **البرهان (18–25 ث):** نتيجة، تقييم عميل، أو لقطة قبل/بعد.
5. **CTA (25–30 ث):** فعل واضح + إلحاح: «اطلبه الآن — الرابط في البايو».

## مخرجات لكل سكريبت

```
الزاوية: …
3 خطّافات مقترحة: … / … / …
المشهد ↓ (التوقيت | ما يُقال voiceover | ما يُعرض on-screen | نص مكتوب overlay)
  0–3 ث  | … | … | …
  ...
CTA النهائي: …
كلمات مفتاحية/هاشتاغات: …
الموسيقى/الإيقاع المقترح: …
```

## قواعد المنصّات

- **TikTok:** عفوي، شبيه بمحتوى المستخدم (UGC)، عمودي 9:16، نص overlay كبير،
  الصوت أهم من الإنتاج المصقول.
- **Reels/Instagram:** أنظف بصرياً قليلاً، نفس البنية، تجنّب علامة TikTok المائية.
- اكتب لغة الكلام الطبيعية (دارجة/عامية حسب السوق) لا لغة الكتب.

## قواعد

- لا تعِد بوعود كاذبة أو ادعاءات طبية؛ التزم بسياسات إعلانات المنصّات.
- اكتب **2–3 زوايا مختلفة** عند الإطلاق لاختبارها (creative testing).
- لتشغيل الحملة فعلياً أو إنشاء كود خصم، مرّر العمل لوكالة التسويق
  (`ds-marketing`) بعد موافقة المستخدم.

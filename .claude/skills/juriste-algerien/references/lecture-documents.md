# قراءة وتحليل الوثائق المصوّرة — Analyse de documents

عندما يرسل المستعمل **صورة وثيقة**، اتبع هذا البروتوكول قبل أي تحليل قانوني.

---

## 1. البروتوكول العام (بالترتيب)

**① تحديد نوع الوثيقة** — استعن بالجدول أدناه (الترويسة والختم والتوقيع تكشفان النوع فوراً).

**② استخراج المعطيات الحرجة** وأعد كتابتها للمستعمل في جدول:
- **الجهة المُصدِرة** (محكمة/قسم، بلدية، مديرية، بنك، مؤسسة، موثّق، محضر قضائي)،
- **الأطراف** بالكامل،
- **رقم الملف / الفهرس / الجدول (numéro de rôle ou de répertoire)**،
- **التواريخ الثلاثة**: تاريخ **تحرير** الوثيقة، تاريخ **النطق** بالحكم، **تاريخ التبليغ الرسمي** ← وهذا الأخير هو الذي تسري منه الآجال،
- **الطابع والتوقيع**: هل الوثيقة موقّعة ومختومة؟ وثيقة بلا ختم ولا توقيع لا قيمة رسمية لها،
- **المنطوق أو المضمون العملي**: ماذا تقرّر الوثيقة بالضبط؟

**③ حساب الأجل فوراً** — قبل أي تحليل في الموضوع:
> أجل الطعن = تاريخ التبليغ + المدة القانونية. اذكر **التاريخ النهائي بالرقم** («آخر أجل: 18/09/2026»)، وكم بقي من الأيام حسب تاريخ اليوم. إن كان الأجل قد فات، قلها بوضوح فوراً واعرض ما تبقّى من طرق (التماس إعادة النظر، تنفيذ، تفاوض).

**④ الإشارة إلى النقص** — إن كانت الصورة غير واضحة أو ناقصة أو مقطوعة، **اطلب إعادة تصوير الجزء الناقص** بدل التخمين. ⚠️ **لا تخمّن أبداً رقماً أو تاريخاً أو اسماً غير واضح في الصورة** — اطلبه.

**⑤ التحليل القانوني** — ثم فقط طبّق منهجية `SKILL.md` (الوقائع ← التكييف ← النص ← الاختصاص ← الحلول…).

## 2. الوثائق الجزائرية الشائعة — ماذا تستخرج من كل واحدة

### وثائق قضائية

| الوثيقة | ما تستخرجه | الأجل الذي تُطلقه |
|---|---|---|
| **تكليف بالحضور / استدعاء للجلسة** (citation à comparaître) | المحكمة، القسم، **تاريخ وساعة الجلسة**، رقم الجدول، صفة المستدعى (مدعى عليه/شاهد/متهم) | لا أجل طعن — لكن **الغياب يؤدي إلى الفصل غيابياً**. حضّر مذكّرة ووثائق قبل الجلسة |
| **محضر تبليغ رسمي** (PV de signification) بمحضر قضائي | اسم المحضر القضائي، **تاريخ التبليغ**، طريقته (شخصياً / لموطنه / تعليقاً)، الوثيقة المبلَّغة | ⚠️ **هذا التاريخ هو الذي تسري منه كل الآجال** |
| **حكم** (jugement) — محكمة | رقم الفهرس، تاريخ النطق، **حضوري أم غيابي**، **المنطوق كاملاً**، هل فيه **نفاذ معجّل** | استئناف: **شهر** مدني / **10 أيام** جزائي. غيابي ⇒ **معارضة** |
| **قرار** (arrêt) — مجلس قضائي | تأييد أم إلغاء أم تعديل، المنطوق | **نقض**: شهران مدني / 8 أيام جزائي |
| **أمر استعجالي** (ordonnance de référé) | التدبير المأمور به، النفاذ المعجّل | استئناف: **15 يوماً** |
| **أمر بالأداء** (injonction de payer) | المبلغ، الأجل الممنوح | أجل الاعتراض — تحقّق منه في ق.إ.م.إ |
| **التكليف بالوفاء** (commandement de payer) | المبلغ، **المهلة الممنوحة قبل التنفيذ الجبري**، السند التنفيذي المستند إليه | بعد المهلة يبدأ الحجز — تحرّك فوراً (تسوية أو إشكال في التنفيذ) |
| **محضر حجز** (PV de saisie) | الأموال المحجوزة، تاريخ البيع بالمزاد | إشكال في التنفيذ أمام رئيس المحكمة |
| **إشعار بحفظ الشكوى** | سبب الحفظ | الطريق: **شكوى مع ادّعاء مدني أمام قاضي التحقيق** |

### وثائق جزائية

| الوثيقة | ما تستخرجه |
|---|---|
| **محضر شرطة / درك** | التكييف المذكور، **ساعة بداية ونهاية التوقيف للنظر**، التصريحات، هل أُعلم الموقوف بحقوقه. ⚠️ تجاوز المدة أو إغفال الحقوق ⇒ **دفع بالبطلان في أول جلسة** |
| **شهادة طبية** | **عدد أيام العجز الكلي المؤقت (ITT)** — هي التي تحدّد وصف الجريمة والعقوبة، تاريخ المعاينة، وصف الإصابات |
| **أمر بألا وجه للمتابعة** | سببه | استئناف أمام **غرفة الاتهام: 3 أيام** |
| **استدعاء للتحقيق** | صفة الاستدعاء (متهم / شاهد / طرف مدني)، الوقائع المنسوبة، التاريخ | حقّ الاستعانة بمحامٍ — نبّه عليه دائماً |

### وثائق العمل

| الوثيقة | ما تستخرجه |
|---|---|
| **قرار التسريح** | السبب المذكور، تاريخه، **هل سبقته جلسة استماع واستدعاء كتابي** ⇒ الإخلال بالإجراء = تسريح تعسّفي ولو كان الخطأ ثابتاً |
| **استدعاء لجلسة الاستماع** | التاريخ، الوقائع المنسوبة، مهلة التحضير |
| **محضر عدم المصالحة** (PV de non-conciliation) | تاريخه ← ⚠️ **منه يبدأ أجل رفع الدعوى أمام القسم الاجتماعي — لا تتأخّر** |
| **كشف الراتب** (fiche de paie) | الأجر القاعدي، التعويضات، **الاقتطاعات الاجتماعية** (دليل التصريح لدى CNAS)، الأقدمية |
| **شهادة الانتماء CNAS / كشف المسار المهني** | السنوات المصرّح بها ← اكتشاف **سنوات غير مصرّح بها** |
| **عقد العمل** | CDI أم CDD، **سبب اللجوء إلى CDD** (خارج الحالات القانونية ⇒ إعادة تكييف إلى CDI)، فترة التجربة |

### وثائق عقارية

| الوثيقة | ما تستخرجه |
|---|---|
| **الدفتر العقاري** | رقم القسم والمخطط، المساحة، اسم المالك، **الحقوق والرهون المقيّدة** |
| **عقد توثيقي** | اسم الموثّق، **مرجع الشهر بالمحافظة العقارية** (بدونه لا يُحتجّ به على الغير)، الثمن، الحدود |
| **عقد عرفي** | التوقيعات، الثمن ووصل دفعه، الشهود، وصف العقار ⇒ **دعوى إتمام إجراءات البيع** |
| **شهادة الحيازة** | تثبت الحيازة **لا الملكية** |
| **رخصة بناء / شهادة مطابقة / محضر مخالفة** | التاريخ، الجهة، المخالفة المعاينة، **أجل التظلّم: 4 أشهر** |
| **قرار هدم / نزع ملكية** | تاريخ التبليغ ⇒ **دعوى إلغاء + طلب وقف التنفيذ عاجل** |

### وثائق تجارية ومالية

| الوثيقة | ما تستخرجه |
|---|---|
| **شيك مرفوض + شهادة عدم الدفع** | المبلغ، تاريخ الإصدار، تاريخ التقديم، سبب الرفض ⇒ **شكوى جزائية + دعوى تحصيل** |
| **فاتورة / وصل طلبية** | رقمها، تاريخها، الطرفان، الرقم الجبائي، المبلغ، شروط الدفع |
| **كشف حساب بنكي / CCP / BaridiMob** | إثبات الدفع أو التحويل — دليل مركزي في قضايا النصب الإلكتروني |
| **السجل التجاري** | رقم القيد، النشاط المصرّح به، المسيّر، المقر |
| **القانون الأساسي للشركة** | الحصص، صلاحيات المسيّر، بنود التنازل وفضّ النزاع |

### وثائق إدارية وأسرية

| الوثيقة | ما تستخرجه |
|---|---|
| **قرار إداري** (arrêté / décision) | الجهة، **تاريخ التبليغ**، التسبيب (انعدامه عيب شكلي)، هل استُشيرت اللجنة الإلزامية ⇒ **تظلّم ودعوى إلغاء: 4 أشهر** |
| **وصل إيداع ملف** | تاريخه وختمه ← يُثبت أن الإدارة تسلّمت الملف؛ **سكوتها = رفض ضمني** |
| **عقد زواج / شهادة عائلية** | التواريخ، الشروط المدرجة في العقد (عدم التعدّد، السكن، العمل) |
| **عقد الفريضة** | الورثة وأنصبتهم — أساس دعوى القسمة |
| **محادثات ولقطات شاشة** | التواريخ الظاهرة، أرقام الهواتف، أرقام الحسابات، الروابط. ⚠️ اطلب لقطات **كاملة غير مقصوصة** تُظهر التاريخ والمُرسِل |

## 3. جودة الصورة — ما تطلبه من المستعمل

- **الصفحة كاملة بزواياها الأربع**، بما فيها **الترويسة والتذييل** (فيهما رقم الملف والتاريخ والختم)،
- **كل الصفحات**، مرقّمة بالترتيب — وخاصة **الصفحة الأخيرة** فيها المنطوق والتوقيع والختم،
- **ظهر الوثيقة** إن كان فيه كتابة أو ختم تبليغ،
- إضاءة جيدة، بلا ظلّ ولا انعكاس، والنصّ مستقيم،
- تصوير **قريب ومنفصل** للختم وتاريخ التبليغ إن كانا غير واضحين.

**نبّه المستعمل**: إن أراد، يمكنه **إخفاء رقم بطاقة التعريف ورقم الحساب البنكي** — التحليل القانوني لا يحتاجهما، ويكفي أن يقول «الوثيقة باسمي».

---

## 4. ما لا يجوز فعله بالصور

- **لا تخمّن** كلمة أو رقماً أو تاريخاً غير مقروء — اطلب إعادة التصوير. تاريخ مقروء خطأً = أجل محسوب خطأً = حق ضائع.
- **لا تجزم بصحة وثيقة أو بتزويرها** من صورة. أقصى ما يقال: «هذه الوثيقة تفتقد الختم/التوقيع/مرجع الشهر، وهو ما يضعف قيمتها الرسمية»، والطعن بالتزوير له إجراء قضائي خاص (**دعوى الطعن بالتزوير الفرعية أو الأصلية**).
- **لا تساعد** في تعديل وثيقة أو إعادة صياغتها بشكل يغيّر مضمونها الأصلي.
- ذكّر بأن **الأصل هو المعتمد** أمام القضاء، والصورة مجرد وسيلة للتحليل: احتفظ بالأصول ولا تودعها إلا مقابل وصل.

```
🏛️ الجهة المُصدِرة: [.....]
👥 الأطراف: [.....]
🔢 رقم الملف/الفهرس: [.....]
📅 تاريخ التحرير/النطق: [.....]
📬 تاريخ التبليغ: [.....]

⏳ الأجل: [نوع الطعن] — آخر أجل [التاريخ] — بقي [عدد] يوماً
   [أو: ⚠️ الأجل فات بتاريخ ..... — الطرق المتبقية: .....]

📌 ما تقرّره الوثيقة: [المنطوق/المضمون في جملتين]
```

ثم أكمل بالاستشارة الكاملة وفق منهجية `SKILL.md`، واختم بالتنبيه الإلزامي.

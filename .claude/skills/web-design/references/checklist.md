# قائمة المراجعة قبل التسليم — Design QA Checklist

مرّ على كل بند. ما لا ينطبق، تجاوزه؛ ما يفشل، أصلحه قبل التسليم.

## الوضوح والتحويل
- [ ] يفهم الزائر ماذا تقدّم الصفحة ولمن خلال 5 ثوانٍ.
- [ ] CTA رئيسي واحد، ظاهر فوق الطيّة، ومكرّر في نهاية الصفحة.
- [ ] نص الأزرار فعلٌ واضح يصف النتيجة.
- [ ] عناصر الثقة موجودة (آراء، ضمان، تواصل، سياسة الإرجاع/الخصوصية).
- [ ] لا Lorem ipsum ولا روابط `#` منسية (أو مذكورة للمستخدم صراحة).

## البصري
- [ ] تسلسل بصري واضح: عنوان واحد h1، ثم h2 للأقسام، بلا قفز في المستويات.
- [ ] كل الألوان والمسافات من التوكنز؛ لا قيم عشوائية.
- [ ] 2 خطوط كحد أقصى؛ طول السطر ≤ ~75 حرفاً.
- [ ] زوايا وظلال وأحجام أزرار متّسقة.
- [ ] المحاذاة نظيفة؛ المسافات بين الأقسام منتظمة.

## التجاوب
- [ ] يعمل على 320px بلا تمرير أفقي.
- [ ] مُختبر على 375 / 768 / 1024 / 1440px.
- [ ] أهداف اللمس ≥ 44×44px ومتباعدة.
- [ ] الصور لا تتمدّد ولا تتشوّه؛ النصوص لا تفيض من البطاقات.
- [ ] القائمة تعمل على الهاتف ويمكن إغلاقها.

## RTL واللغات
- [ ] `lang` و `dir` صحيحان.
- [ ] لا `left/right` ثابتة؛ خصائص منطقية فقط.
- [ ] الأسهم الاتجاهية معكوسة في RTL؛ الأرقام والشعارات لا.
- [ ] لا `letter-spacing` على العربية؛ الخط العربي محمّل فعلاً.

## الوضع الداكن
- [ ] كل الألوان معرّفة للوضعين؛ لا نص داكن على خلفية داكنة.
- [ ] الصور/الشعارات مقروءة على الخلفيتين.
- [ ] `color-scheme: light dark` لعناصر النماذج وأشرطة التمرير.

## سهولة الوصول (WCAG AA)
- [ ] تباين النص ≥ 4.5:1 (الكبير ≥ 3:1).
- [ ] كل عنصر تفاعلي يُوصَل إليه بلوحة المفاتيح، مع `:focus-visible` ظاهر.
- [ ] HTML دلالي: `header` `nav` `main` `section` `footer`، أزرار `<button>` وروابط `<a>`.
- [ ] `alt` للصور، `label` للحقول، `aria-label` للأزرار ذات الأيقونة فقط.
- [ ] رابط "تخطَّ إلى المحتوى".
- [ ] احترام `prefers-reduced-motion`.
- [ ] المعلومة لا تُنقل باللون وحده.

## الأداء
- [ ] الصور مضغوطة، بأبعاد صريحة، و`lazy` تحت الطيّة؛ صورة الهيرو `fetchpriority="high"`.
- [ ] الخطوط: أوزان محدودة، `display=swap`، `preconnect` لـ Google Fonts.
- [ ] لا مكتبات ثقيلة لمهمّة بسيطة؛ JS مؤجَّل (`defer`).
- [ ] لا قفزات تخطيط (CLS) عند التحميل.

## SEO والمشاركة
- [ ] `<title>` فريد (≤ 60 حرفاً) و`meta description` (≤ 155 حرفاً).
- [ ] `meta viewport` موجود.
- [ ] Open Graph (`og:title`, `og:description`, `og:image`) و favicon.
- [ ] روابط وصفية، وعنوان h1 واحد يحتوي الكلمة المفتاحية.

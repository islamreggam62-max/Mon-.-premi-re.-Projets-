# نموذج: بوردورو الإرسال — Bordereau d'envoi

> يُستعمل بدل الرسالة حين يكون الإرسال **مجرّد تحويل وثائق** (إرسال للتأشير، إرجاع بعد
> التأشير، تحويل نسخ). الرسالة تُحرَّر حين يكون هناك **موقف أو تعليمة**؛ البوردورو حين تكون
> الوثائق وحدها هي الرسالة.

---

## 10.1 — الهيكل الثابت

```
[LOGO NAFTAL]
BRANCHE CARBURANTS
DIRECTION JURIDIQUE
N°            /D.JUR/[année]

                            BORDEREAU D'ENVOI

┌──────────────────────────────────┬──────────────────────────────────────┐
│                                  │ DATE : [JJ/MM/AAAA]                  │
│            EXPEDITEUR            │            DESTINATAIRE              │
├──────────────────────────────────┼──────────────────────────────────────┤
│        DIRECTION JURIDIQUE       │        [DIRECTION DESTINATAIRE]      │
└──────────────────────────────────┴──────────────────────────────────────┘

┌────────────────────────────────────────────────┬─────────┬───────────────┐
│                  Désignations                  │ Nombre  │ Observations  │
├────────────────────────────────────────────────┼─────────┼───────────────┤
│ Veuillez trouver ci-joint :                    │         │               │
│                                                │         │               │
│ 1- [DÉSIGNATION EXACTE DU DOCUMENT, N°, OBJET] │   01    │ [Pour visa /  │
│    [PARTENAIRE : …]                            │         │  Visé /       │
│                                                │         │  Pour         │
│ 2- [AUTRE DOCUMENT]                            │   01    │  information] │
│                                                │         │               │
│    Bonne réception                             │         │               │
│                                                │         │               │
│                       LA DIRECTRICE JURIDIQUE  │         │               │
│                              M.LAMANI          │         │               │
└────────────────────────────────────────────────┴─────────┴───────────────┘

Reçu le    :
Nom        :
Signature  :
```

**قواعد**:
- **الوثيقة تُسمّى بكاملها**: النوع + الرقم + الموضوع + المتعامل — لا اختصار،
- **العدد رقماً في خانة `Nombre`** (`01`, `02`)،
- خانة `Observations` تحمل **الغرض**: `Pour visa` عند الإرسال، `Visé` عند الإرجاع،
  `Pour information`, `Pour signature`, `Pour suite à donner`,
- **`Bonne réception`** قبل التوقيع،
- **`Reçu le / Nom / Signature`** أسفل الصفحة: هي **إثبات التسليم** — تُملأ ويُحتفظ بالنسخة
  في الملف. بوردورو بلا وصل استلام موقّع لا يُثبت شيئاً،
- رقم الـ chrono يُترك فارغاً لمكتب الضبط.

---

## 10.2 — إرجاع وثيقة بعد التأشير القانوني

في خانة `Observations` تُكتب `Visé`، والوثائق المُعادة تُعدّ سطراً سطراً:

```
1- [AVENANT / CONTRAT] N° […] RELATIF À […] — PARTENAIRE : […]     01     Visé
2- FICHE D'EXAMEN ET DE VALIDATION DES CLAUSES CONTRACTUELLES      01     Signée
```

⚠️ إن كانت هناك **تحفّظات**، لا يُستعمل البوردورو وحده: تُرفَق **مذكّرة الملاحظات**،
أو تُحرَّر رسالة بالنموذج `09-visa-projets-contrat.md` §9.2.

---

## 10.3 — متى رسالة ومتى بوردورو؟

| الحالة | الوثيقة |
|---|---|
| إرسال وثائق للتأشير أو للإعلام | **بوردورو** |
| إرجاع وثائق مؤشَّرة بلا تحفّظ | **بوردورو** (أو رسالة 9.1 حسب العادة المتّبعة مع الهيكل) |
| إرجاع مع تحفّظات أو تعليمات | **رسالة** (9.2) |
| طلب استكمال ملف | **رسالة** (9.3) |
| إعذار، فسخ، تطبيق غرامات، تفعيل كفالة | **رسالة** حصراً — لا بوردورو أبداً |

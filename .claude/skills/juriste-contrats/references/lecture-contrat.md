# قراءة عقد وارد — Analyser un contrat, un projet ou un cahier des charges reçu

يُطبَّق حين يرسل المستعمل **مشروع عقد، عقداً موقّعاً، دفتر شروط، ملحقاً، كفالة، أو صورة/PDF**
ويطلب رأياً. الهدف: **إخراج بطاقة العقد وجدول المخاطر في أقل من صفحتين**.

---

## 1. قبل التحليل — ما يجب التأكّد منه

☐ هل الوثيقة **كاملة**؟ (الصفحات مرقّمة ومتسلسلة؟ الملاحق المذكورة مرفقة فعلاً؟)
☐ هل هي **مشروع (projet)** أم **نسخة موقّعة**؟ الفرق يغيّر كل الاستشارة:
  مشروع ⇒ نتفاوض ونعدّل • موقّع ⇒ نبحث عن الوسائل داخل النص لا خارجه.
☐ هل هي **نسختنا** أم **نسخة الطرف الآخر**؟ (نسخة الطرف الآخر تُقرأ بعين الخصم).
☐ ما تاريخها ورقم إصدارها (V1/V2)؟

⚠️ **لا تُخمّن أبداً**: رقماً، مبلغاً، تاريخاً، اسماً، رقم بند، أو كلمة غير واضحة في صورة.
اطلب إعادة تصوير الجزء الناقص. المبلغ المقروء خطأ = استشارة خاطئة كاملة.
⚠️ **الصفحات الناقصة**: قل صراحةً «التحليل يشمل الصفحات […] فقط؛ الصفحات […] ناقصة وقد
تتضمّن بنوداً حاسمة (الضمانات، الجزاءات، الاختصاص)».

## 2. الاستخراج — Fiche contrat (جدول إلزامي في أول الجواب)

| العنصر | المستخرَج |
|---|---|
| نوع الوثيقة | عقد / ملحق / دفتر شروط / عرض / كفالة |
| الأطراف | التسمية، الشكل القانوني، السجل التجاري، المقر |
| **الموقّعان وصفتهما** | الاسم، الصفة، سند التفويض إن ذُكر |
| الموضوع | بجملة واحدة دقيقة |
| المبلغ | بالأرقام + بالحروف + العملة + HT/TTC |
| المدة / الآجال | تاريخ السريان، المدة، نقطة انطلاق الآجال |
| الدفع | الأجل، الشروط المسبقة، التسبيقات |
| الضمانات | نوعها، مبلغها، **تاريخ انتهاء صلاحيتها** |
| الجزاءات | نسبة الغرامة، السقف |
| الفسخ | الحالات، الإعذار، الأجل |
| النزاع | القانون المطبَّق، المحكمة أو التحكيم |
| **الملاحق المذكورة** | قائمتها + هل هي مرفقة؟ |

## 3. الفحص السريع — 12 إشارة حمراء تُبحث فوراً (Ctrl+F)

ابحث في النصّ عن هذه الكلمات بالضبط — وجودها أو **غيابها** هو الخبر:

| ابحث عن | ما يعنيه |
|---|---|
| `tacite reconduction` | تجديد ضمني — يُقيَّد أو يُحذف |
| `sauf` / `à l'exception de` | الاستثناءات هي حيث يُخبَّأ الخطر |
| `réputé(e)` / `est présumé` | قرينة مفروضة (استلام ضمني، قبول ضمني) |
| `limitation de responsabilité` / `plafonné` | سقف مسؤولية لصالح الطرف الآخر |
| `dommages indirects` | استبعاد أضرار قد تكون هي الأهمّ |
| `de plein droit` | أثر تلقائي — لصالح من؟ |
| `à première demande` | كفالة قوية (نريدها لنا) |
| `sous réserve de` | تعليق التزام على شرط |
| `nonobstant` | استثناء يعلو على بند آخر |
| `frais à la charge de` | توزيع المصاريف |
| `résiliation` / `résolution` | تحقّق من التوازن بين الطرفين |
| `compétence` / `arbitrage` / `droit applicable` | **إن غابت: خطر كبير** |

**والغياب أخطر من الحضور**: إن لم تجد `pénalité`، `caution`, `assurance`, `réception`,
`confidentialité`, `HSE`, `sous-traitance` ⇒ اذكرها في قائمة **البنود الغائبة**.

## 4. حساب الآجال — Le réflexe des dates

من كل وثيقة، احسب فوراً وأعطِ **التاريخ بالرقم**:
- تاريخ نهاية الأجل التعاقدي = تاريخ ODS + الأجل + أيام التوقيف،
- تاريخ انتهاء صلاحية **الكفالة** ⇒ هل يغطّي نهاية العقد + هامش؟ **إن لا: 🔴 تنبيه فوري**،
- نهاية فترة الضمان ⇒ متى يجوز رفع اليد؟
- أجل الردّ على مطالبة أو تحفّظ أو عرض ⇒ كم بقي من الأيام؟
- أجل التقادم إن كان النزاع قديماً.

اكتبها في صدر الجواب: `⏰ [التاريخ] — بقي [x] يوماً`.

## 5. إخراج التحليل

اتبع `modeles/note-analyse-contrat.md`. الحدّ الأدنى المقبول:
1. **بطاقة العقد** (الجدول أعلاه)،
2. **⏰ الآجال الحرجة** في صدر الجواب،
3. **جدول المخاطر**: البند → الخطر → 🔴/🟠/🟢 → **الصياغة البديلة**،
4. **البنود الغائبة**،
5. **القرار**: ✅ يُوقَّع / 🟠 يُوقَّع بعد تعديل [البنود] / 🔴 لا يُوقَّع + السبب،
6. **الخطوة التالية** والمعطيات الناقصة المطلوبة من المستعمل.

⚠️ **ما لا يجوز**: الجزم بصحة توقيع أو ختم أو وثيقة انطلاقاً من صورة؛ ولا تأكيد أن العقد
«مطابق للقانون» إجمالاً — التحليل يخصّ **ما ورد في الوثيقة المقروءة** فقط، ويُقال ذلك صراحةً.

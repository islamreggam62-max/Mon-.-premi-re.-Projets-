# كتابة أوصاف وعناوين المنتجات

هدفك: صفحة منتج **تبيع** وتظهر في البحث. لا تخترع مزايا غير موجودة، ولا تعِد
بوعود طبية/قانونية كاذبة.

## قبل الكتابة — اجمع هذه المعلومات

إن نقص أيٌّ منها، اسأل المستخدم سؤالاً واحداً موجزاً أو استنتجه من صورة المنتج:

- **المنتج ووظيفته الأساسية** (ماذا يحل من مشكلة؟).
- **الجمهور والسوق/اللغة** (عربي؟ دارجة؟ إنجليزي؟ سوق الخليج/المغرب/…؟).
- **أهم 3–5 مزايا** ونقاط التميّز عن المنافس.
- **السعر** ونطاق التوصيل إن توفّر.

## العنوان (Title)

- 50–60 حرفاً كحدّ أقصى، الكلمة المفتاحية الرئيسية في البداية.
- الصيغة: `[الكلمة المفتاحية] + [الميزة/الفئة] + [تفصيل مميّز]`.
- بدون CAPS مبالغ فيه ولا رموز تعبيرية في العنوان.
- مثال: `سماعة بلوتوث لاسلكية — عزل ضجيج، بطارية 30 ساعة`.

## الوصف (Description) — بهذا الترتيب

1. **جملة خطّاف (Hook):** سطر يلمس المشكلة أو الرغبة مباشرة.
2. **الفوائد قبل الخصائص:** حوّل كل خاصية إلى منفعة للعميل
   («بطارية 30 ساعة» ⇐ «يكفيك أسبوعاً كاملاً دون شحن»).
3. **قائمة نقطية** لأهم 4–6 مزايا (سهلة المسح البصري).
4. **معالجة الاعتراضات:** الجودة، التوصيل، الضمان/الإرجاع.
5. **دعوة للفعل (CTA):** واضحة ومحفّزة («اطلبه الآن قبل نفاد الكمية»).

## قواعد الـ SEO

- ضع الكلمة المفتاحية في: العنوان، أول 100 كلمة، عنوان فرعي واحد، ونص `alt`
  للصورة، ورابط المنتج (handle).
- اكتب **Meta description** من 150–160 حرفاً تلخّص المنفعة + CTA.
- استخدم كلمات مفتاحية طويلة الذيل (long-tail) يبحث بها العميل فعلاً.
- لا تحشُ الكلمات المفتاحية (keyword stuffing) — يضرّ الترتيب والقراءة.

## المخرجات — سلّمها بهذا الشكل

```
العنوان: …
الـ handle (رابط): …
الوصف: … (بصيغة HTML/Markdown جاهزة للصق في Shopify)
Meta description: …
نص alt للصورة: …
3 كلمات مفتاحية مقترحة: …
```

## قواعد

- إن كان الطلب يشمل **الكتابة الفعلية في المتجر**، لا تكتب بنفسك: مرّر النص
  الجاهز إلى وكالة بناء المتجر (`ds-store-builder`) بعد موافقة المستخدم.
- أجب بلغة المستخدم افتراضاً. للسوق ثنائي اللغة، قدّم النسختين.
